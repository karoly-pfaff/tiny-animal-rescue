# Visual QA

## Every asset

- Correct dimensions, aspect ratio, color space, and transparency behavior.
- No watermark, unintended logo, accidental glyph, malformed text, or signature.
- No duplicated limb, prop, facial feature, or important object.
- Shapes remain readable at intended display size.
- Lighting, palette, materials, rendering style, and character proportions match the style lock.
- Nothing important is clipped at the edge.

## Production scenes

- No baked UI or player-facing text.
- Runtime-safe corners remain quiet enough for controls.
- Source, target, and interaction corridor are unobstructed.
- Foreground decoration does not cover hit areas.
- The problem and success state can be staged clearly.
- Portrait adaptation can crop decorative margins without losing gameplay.

## Characters and props

- Genuine transparent background where requested.
- Entire asset is visible with generous padding.
- No ground, environment, pedestal, base, or cast shadow unless required.
- Character identity remains consistent across poses.
- Prop perspective matches its intended scene and does not imply an unusable orientation.

## Presentation mockups and localization edits

- Exact copy is spelled correctly and fully replaces the old text.
- Text hierarchy, alignment, perspective, surface integration, outline, and shadow remain coherent.
- No unrelated visual element changed.
- Mark the result as presentation-only when it contains baked UI text.
