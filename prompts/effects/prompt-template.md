# Effects prompt template

```text
Runtime ID: effects.<DOMAIN>.<NAME>
Use: <PLAYER ACTION OR GAME EVENT>
Output: <ONE-SHOT OR LOOP>, <MONO OR STEREO>, <TARGET DURATION>
Variants: <COUNT AND TYPE OF VARIATION>

Prompt:
Create <EXACTLY ONE SOUND>. Describe the physical source, emotional meaning,
timing/envelope, brightness, weight, and tail. Apply the Tiny Rescue effects style
lock. State what must not appear.

Acceptance:
- <AUDIBLE PROPERTY THAT MUST BE PRESENT>
- <REASON TO REJECT A CANDIDATE>
```

Do not ask a generator for an entire sound pack in one prompt. Separate files are easier to select, edit, name, mix, and regenerate.
