# Suno music prompts

## Recommended generation approach

- Select instrumental generation when available. Otherwise use `[Instrumental]` as the complete lyric input.
- Paste only the fenced `Suno style prompt` from the selected track file into the style field.
- Generate at least three candidates per track.
- Favor stable middle sections over impressive introductions or endings.
- Derive the final loop in an audio editor; generation is source material, not the final mastered game asset.

## Loop strategy

Generated songs often contain an obvious opening, development, and ending. For game use:

1. select a steady 45–120 second middle section;
2. cut near matching harmonic and textural points;
3. use a short equal-power crossfade;
4. test at least ten continuous repetitions;
5. reject loops with accumulating fatigue, exposed transition clicks, or a melody that demands attention.

## Location continuity

All tracks share the project music style lock, while each place gets one identifying instrument or texture. Reuse a small three- or four-note rescue-center motif subtly across Start, Map, Shelter, and Celebration so the game feels like one world.
