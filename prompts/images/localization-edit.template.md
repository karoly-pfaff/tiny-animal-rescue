# Localization edit template

Use only for an existing presentation mockup. Production art must not contain baked UI text.

```text
Use case: text-localization
Asset type: Tiny Rescue presentation mockup localization
Classification: presentation-only
Input image: edit target

Primary request:
Replace every listed source-language text element with the exact target-language
text. Do not redesign or regenerate the screen.

Exact replacements:
- "<SOURCE>" -> "<TARGET>"
- "<SOURCE>" -> "<TARGET>"

Typography:
Preserve the original playful rounded lettering, hierarchy, colors, outlines,
shadows, alignment, surface perspective, and spacing. Fit translated text naturally
without changing the surrounding UI.

Constraints:
Apply the localization-edit negative constraints. Completely remove original
glyphs. Target spelling must be exact and legible. No added text or object.
```
