# Screen concept template

Use for presentation/pitch mockups. If text or UI is rendered into the image, classify the result as presentation-only.

```text
Use case: ui-mockup
Asset type: Tiny Rescue <START | MAP | SHELTER | MISSION | CELEBRATION> screen concept
Classification: presentation-only

Primary request:
Create a polished landscape tablet-game mockup showing <SCREEN PURPOSE>.

Scene/backdrop:
<ENVIRONMENT, TIME OF DAY, LANDMARKS>

Characters:
<NAMES, SPECIES, POSES, EXPRESSIONS>

Runtime UI represented in the mockup:
<CONTROL, ICON, POSITION, PRIORITY>

Text (verbatim):
- "<EXACT ENGLISH COPY>"
- "<EXACT ENGLISH COPY>"

Style:
Apply the Tiny Rescue visual style lock.

Composition:
Landscape 4:3, designed for a 1024×768 surface. Keep the primary action dominant,
the parent-facing action visually secondary, and all touch targets large and
separated. Preserve quiet corners for safety navigation where appropriate.

Constraints:
Use only the listed copy and controls. Text must be exact, legible, and integrated
with the rounded wooden/painted UI surfaces. This is a presentation mockup, not a
production background.

Avoid:
Apply the global and presentation-mockup negative constraints.
```
