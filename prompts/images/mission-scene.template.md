# Mission scene template

Use for a clean production scene or compositional concept without runtime UI.

```text
Use case: illustration-story
Asset type: Tiny Rescue mission scene
Classification: production candidate
Mission ID: <MISSION-ID>

Primary request:
Create the clean illustrated scene for <MISSION SUMMARY>.

Scene/backdrop:
<LOCATION, WEATHER, LANDMARKS, REQUIRED ENVIRONMENTAL STORY CUES>

Characters:
<SUBJECT AND HELPER; POSES AND SAFE EMOTIONS>

Interactive composition:
- source: <OBJECT, POSITION, REQUIRED VISIBILITY>
- target: <OBJECT/ZONE, POSITION, REQUIRED VISIBILITY>
- interaction corridor: <CLEAR ROUTE>
- success-state requirement: <HOW THE SCENE CAN CHANGE>

Style:
Apply the Tiny Rescue visual style lock.

Composition:
Landscape 4:3 on a 1024×768 design surface. State normalized placement or broad
screen regions. Keep runtime-control safe areas visually quiet. Portrait adaptation
may crop only decorative margins.

Technical requirements:
<SINGLE FLATTENED CONCEPT | LAYER PLAN | BACKGROUND ONLY>
<OUTPUT DIMENSIONS AND FORMAT>

Constraints:
Apply the global and production-scene negative constraints. The production image
must contain no UI or text.
```
