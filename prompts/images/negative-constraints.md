# Negative constraints

Select the relevant groups and include them under `Avoid` or `Constraints`.

## Global

```text
Avoid: watermark, signature, brand logo, unrelated text, pseudo-writing,
distorted anatomy, duplicated limbs, duplicated animals, malformed paws,
asymmetrical eyes, uncanny expression, photorealistic suffering, dirt or injury
detail, dark horror mood, visual clutter, excessive depth blur, crushed shadows,
overexposed highlights, unrelated props, and cropped focal subjects.
```

## Production scene

```text
No baked UI, buttons, labels, title, letters, numbers, instruction arrows,
hand pointer, progress tracker, logo, watermark, or sign containing text.
Do not place decoration over interaction sources, targets, corridors, or UI safe zones.
```

## Character or prop cutout

```text
Genuinely transparent background. No environment, floor, ground patch, platform,
pedestal, base, frame, border, text, watermark, or cast shadow. Do not crop any
part of the subject. No unrelated accessory.
```

## Presentation mockup

```text
No misspelled, invented, duplicated, or truncated UI copy. Do not add controls,
characters, counters, badges, or labels not explicitly listed. Do not imitate
a real commercial brand or include a watermark.
```

## Localization edit

```text
Change only the enumerated text. Do not redesign or regenerate the composition,
characters, props, controls, icons, background, palette, lighting, materials,
dimensions, or spacing. Remove the original glyphs completely.
```
